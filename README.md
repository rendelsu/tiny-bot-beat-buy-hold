A tiny deterministic trading bot for hourly Solana bars: it stays in cash until a symbol shows a clear uptrend, holds up to three such symbols near 23% of equity each, exits on a wide trend break or a 6% loss against cost, and rebalances every 4 bars with a 150 USDC minimum trade. Built by an AI agent for make.fun's "Tiny Bot, Easy $2: Beat Buy-and-Hold on Solana" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```
